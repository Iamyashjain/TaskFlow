# **App Name**: TaskFlow

## Core Features:

- Google Sign-In: Implement Google Sign-In for authentication. Upon successful login, display the user's name and profile photo.
- Improved Layout: Responsive sidebar navigation with icons for: Dashboard, Create Task, Logout.  Sticky top navbar showing user's Google avatar or initials. Two-column layout for desktop and one-column for mobile.
- Enhanced UI Elements: Apply shadows and rounded corners to cards and forms for a polished look.  Use Tailwind spacing for a clean, consistent layout. Implement dark mode with a toggle button.
- Smooth Animations: Use transitions for component loading, button hover effects, and custom fade/slide animations to enhance the user experience.
- Toast Notifications: Use react-hot-toast with custom themes for success, error, and info messages displayed at the top right.

## Style Guidelines:

- Primary color: Google Blue (#1A73E8) for main elements.
- Accent color: Google Yellow (#FBBC05) for interactive elements.
- Background color: Light gray (#F8F9FA) for a clean interface.
- Font: 'Inter', a sans-serif, for body and headings; modern and readable.
- Use Google Material Icons, assigning icons to tasks based on status: pending, completed, overdue.
- Responsive design with sidebar navigation.  Two-column layout on desktop and one-column on mobile devices.
- Subtle transitions for component load. Button hover effects include scaling. Custom fade/slide animations where appropriate.
